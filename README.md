# ねこの居場所 — Cat Queens

5〜12のサイズを選んで遊ぶ、猫のQueens系パズル。Vanilla HTML / CSS / JavaScriptのみで動作し、外部通信・バックエンド・ビルドは不要です。

## 遊び方

- 各行・列・色領域に猫を1匹ずつ配置します。上下左右斜めに隣接できません（離れた斜めはOK）。
- タップは指を離した時点で状態を切り替え、空白から×への表示だけ180ms待ちます。300ms以内に同じセルをもう一度タップすると、最初のタップを猫の配置・解除に置き換えます。180msより速いダブルタップでは途中の×を表示しません。×のダブルタップは×に戻り、猫を配置できません。猫や×の単タップによる消去、スワイプの表示は即座に反映します。
- 空白からドラッグ／スワイプすると通過した空白に×を付けます。×から開始すると通過した×を空白に戻します。どちらも猫は変更しません。
- ルール・操作方法は盤面の上で表示／非表示を切り替えられます（初期状態は非表示）。キーボードでの盤面操作はMVP対象外です。
- 「ひとつ戻す」はスワイプ全体や「盤面クリア」も取り消せます。「やり直す」で取り消した操作を再適用できます。新しい操作をするとRedo履歴は消えます。
- 「パズルの作成・共有」は初期状態では閉じています。新しいパズル、盤面サイズ、生成スタイル、共有問題の読み込み、この問題の共有をまとめています。
- 操作ボタンは連打によるダブルタップズームを抑えます。盤面内はスワイプ操作を優先し、スクロールを抑えます。
- 新しいパズル・サイズ変更・ページ再読み込みでは進行状況がリセットされます。

領域の色は固定の12色から、パズル生成ごとに領域番号への割り当てをシャッフルします。盤面クリアでは色と問題は変わりません。

領域番号は盤面や読み上げには表示しません。内部の `puzzle.regions` は従来どおり0始まりで、正解の `row` 行目の猫がいる領域のIDは `row` です（1行目ならID 0）。将来のヒント機能から参照できます。

## 生成スタイル

「次の問題の生成スタイル」で選び、「新しいパズル」で適用します。選ぶだけでは現在の問題は変わりません。サイズ変更時は選択中のスタイルで生成します。表示中の問題のスタイルは別に表示します。形の特徴を選ぶ機能であり、難易度の指定ではありません。

| スタイル | 方法 | 制限 |
| --- | --- | --- |
| RandomSnake（初期値） | ランダムに選んだ猫の領域を広く残し、他の領域を伸ばす | 調整500ms・候補3×n²回まで。広い領域を30%以上残す |
| Balanced | 小さい領域を優先して伸ばし、面積を分散する | 調整500ms・候補3×n²回まで。均等な面積は保証しない |
| SeedGrowth | 各猫から未割り当てセルへ広げ、行き詰まると配置から再試行 | 全体30秒または200回まで。完成しなければエラー |

未割り当ては `-1`。RandomSnake・Balancedは猫の単独領域を置いた後、残りをランダムに選んだ1領域に割り当てて有効な完成盤面を確保します。猫の所属・領域の連結・唯一解を保てる変更だけを採用します。予算切れでは最後の検証済み盤面を返し、探索途中の「未判定」は採用しません。同じ不採用候補を繰り返し調べないことで処理予算を別の候補に使います。猫配置の試行も64回に制限し、上限時は偶数列・奇数列の非隣接配置を使います。

生成中はスタイル名・経過時間・キャンセルを表示します。現在の盤面と入力は成功するまで保持し、キャンセルや失敗で消えません。別の方式への自動切り替えも行いません。500msは調整処理の予算であり、描画・スケジューリングを含む表示までの時間を保証するものではありません。スマホでの通常1秒以内は高速2モードの目標で、実機未測定です。

## 起動・公開

`index.html`をブラウザで開くだけで遊べます。GitHub Pagesではこのフォルダの内容をリポジトリに配置し、Settings → Pagesで公開するブランチのルートフォルダを選択します。すべて相対パスなのでプロジェクト配下でも動作します。

## 問題の共有

「この問題を共有」→「コピー」で共有URLを取得できます。相手がURLを開くと同じ問題を空白の状態から遊べます。URLまたは問題コードを「共有された問題を開く」に貼り付けても読み込めます。ファイルを直接開いている場合は、他の端末では開けないローカルURLの代わりに問題コードを表示します。

共有形式は `CQ1-サイズ-領域データ`。領域データは左上から行順に1セル1文字（0〜b）で格納し、番号は初出順に正規化します。生成器の領域番号に含まれる正解行の情報は引き継ぎません。URLでは `#p=` に格納し、バックエンドや短縮URLサービスは使いません。

読み込み時は唯一解の検証結果から行に対応する内部IDへ戻します。共有URLの形式や領域の形は変わらず、既存の共有コードも読み込めます。

正解の猫配置、入力済みの猫・×、履歴、色の割り当ては共有しません。サイズと領域の形から同じ唯一解が決まります。読み込み時にサイズ・領域の連結・唯一解を検証し、不正なデータは既存の問題を変更せずエラー表示します。これは答えの暗号化ではなく、問題だけを渡す方式です。

## 構成

- `js/solver.js`：行・列・領域・隣接条件による解の探索。
- `js/generator.js`：3スタイルの非同期生成。唯一解・連結を保ち、時間・候補数を制限。
- `js/game.js`：盤面状態、競合・クリア判定、操作履歴。DOMへの依存なし。
- `js/share.js`：問題のみの共有コード・URLの生成と検証。DOMへの依存なし。
- `js/ui.js`：描画、Pointer Eventsによるタップ／スワイプ。
- `js/generation-client.js` / `js/generator-worker.js`：要求ID付きのWorker通信・キャンセル。ファイル直開きやWorker非対応時は同じ非同期生成処理へフォールバックし、約8msごとにイベント処理へ制御を返します。
- `style.css`：スマートフォン優先のレイアウト。

ロジック・入力処理・共有の検証：`node --test tests/*.test.cjs`（Node.jsの標準テストランナーのみ）。入力処理はDOMアダプターで検証しており、スマホ実機での操作確認は別途必要です。


## 生成API・計測

```js
const { puzzle, metrics } = await CatGenerator.generate(12, {
  mode: 'RandomSnake', // Balanced / SeedGrowth
  random: Math.random,
  signal: abortController.signal,
  onProgress: ({ mode, elapsedMs }) => { /* 経過表示 */ }
});
// puzzle: { n, regions, solution, mode }
// metrics: { elapsedMs, evaluations, nodes, attempts, accepted, stopReason }
```

キャンセルは `AbortError`、SeedGrowthの上限は `GenerationTimeoutError`。共有コードは引き続きサイズ・領域形状のみで、modeやmetricsは含みません。共有問題には「共有された問題」と表示します。

`CatSolver.solve()` は同期の解配列を返すAPIを維持します。生成は `solveBudgeted()` を使い、`status: 'complete'` と `status: 'unknown'` を区別します。テストでは `budgetMs`、`maxEvaluations`、`maxAttempts`、`now`、`yieldControl` を注入して予算切れやキャンセルを再現できます。

ベンチマーク：`node scripts/benchmark.cjs`。12×12を高速2モード各100シード、SeedGrowth 20シードで順に生成し、完成した盤面を検証します。結果は `artifacts/generation-benchmark.json`、代表盤面は `artifacts/generation-samples.json`。測定はNode.jsであり、ブラウザ・スマホの実測とは区別します。
