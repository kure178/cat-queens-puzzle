# ねこの居場所 — Cat Queens

5〜12のサイズを選んで遊ぶ、猫のQueens系パズル。Vanilla HTML / CSS / JavaScriptのみで動作し、外部通信・バックエンド・ビルドは不要です。

## 遊び方

- 各行・列・色領域に猫を1匹ずつ配置します。上下左右斜めに隣接できません（離れた斜めはOK）。
- タップで空白と×を切り替え、300ms以内のダブルタップで空白に猫を配置・解除します。×のダブルタップは×のままで、猫を配置できません。猫の単タップは空白に戻します。
- 空白からドラッグ／スワイプすると通過した空白に×を付けます。×から開始すると通過した×を空白に戻します。どちらも猫は変更しません。
- ルール・操作方法は盤面の上で表示／非表示を切り替えられます（初期状態は非表示）。キーボードでの盤面操作はMVP対象外です。
- 「ひとつ戻す」はスワイプ全体や「盤面クリア」も取り消せます。
- 新しいパズル・サイズ変更・ページ再読み込みでは進行状況がリセットされます。

領域の色は固定の12色から、パズル生成ごとに領域番号への割り当てをシャッフルします。盤面クリアでは色と問題は変わりません。

## 起動・公開

`index.html`をブラウザで開くだけで遊べます。GitHub Pagesではこのフォルダの内容をリポジトリに配置し、Settings → Pagesで公開するブランチのルートフォルダを選択します。すべて相対パスなのでプロジェクト配下でも動作します。

## 構成

- `js/solver.js`：行・列・領域・隣接条件による解の探索。
- `js/generator.js`：猫の配置から連結した領域を生成。領域を広げるたびに唯一解を検証。
- `js/game.js`：盤面状態、競合・クリア判定、操作履歴。DOMへの依存なし。
- `js/ui.js`：描画、Pointer Eventsによるタップ／スワイプ。
- `js/generator-worker.js`：Web公開時に盤面生成を別スレッドで実行。ファイルを直接開いた場合はメインスレッドにフォールバックします。
- `style.css`：スマートフォン優先のレイアウト。

ロジック・入力処理の検証：`node --test tests/logic.test.cjs tests/ui.test.cjs`（Node.jsの標準テストランナーのみ）。入力処理はDOMアダプターで検証しており、スマホ実機での操作確認は別途必要です。
